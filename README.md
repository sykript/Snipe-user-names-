# Roblox Name Sniper

A Python username-validation checker designed for Termux on Android.

## Features
- Colored terminal interface
- Roblox username validation
- Results summary
- CSV export

## Requirements
- Android with Termux
- Python 3
- Internet connection

## Run
python roblox_name_sniper_termux.py

## Notes
Username availability can change. API responses may be rate-limited or ambiguous, so results are not guaranteed.

Use responsibly and respect Roblox's terms and limits.
